# QoL Guest Runner

The guest-side service that serves desktop-session control requests inside a disposable qol development guest.

</div>

## Quick start

```bash
cargo run -p qol-guest-runner -- doctor
```

Prepared guests start `qol-guest-runner run` as a service; `qol env` and `qol flow` drive it from the host.
