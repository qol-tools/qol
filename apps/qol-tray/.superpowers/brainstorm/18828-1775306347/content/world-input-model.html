World Viewport — Input Model

How the three input modes interact with the infinite canvas

1

Default Mode — Content Interaction

Mouse clicks, hovers, typing — everything works normally inside the world. The camera is invisible.

Mouse
Click, hover, select — normal
Keyboard
Arrow nav moves between surfaces
Camera auto-follows focused element
2

Edge Panning — Ambient Discovery

Mouse near viewport edge → camera pans in that direction. Speed scales with proximity to edge. No click needed.

↑ pan up
↓ pan down
← pan left
pan right →
content area — normal interaction

Only active when world extends beyond viewport. Dead zone = inner area.

3

CTRL Mode — Explicit Viewport Control

Hold CTRL to enter navigation mode. World content becomes inert. Release to return to default.

CTRL + Arrows
Pan the camera
CTRL + Wheel
Zoom in/out (milestone C)

Future: CTRL held could show contextual overlays (action hints, jump targets)

Camera Behavior

Auto-follow (keyboard nav)

When surface navigation moves focus to an element outside the viewport, the camera pans smoothly to center it. Same intent as scroll-into-view, but as a camera translation.

No zoom in milestone A

World renders at 1x scale. Camera only translates (pan). Zoom comes in milestone C with uniform scaling. CTRL+wheel is reserved but inactive.
