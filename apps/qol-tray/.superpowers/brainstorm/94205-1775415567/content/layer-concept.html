The dive — what happens when you Enter on a hotkey row
    1. You're on Layer 0, viewing Hotkeys page
       Camera: (x: 2400, y: 0, layer: 0, zoom: overview)

    2. Press Enter on "Alt+Tab" row
       → Camera descends: layer 0 → layer -1
       → Zooms in to the "Alt+Tab Editor" sub-page
       → Camera: (x: 2400, y: 200, layer: -1, zoom: 1.0)

    3. The hotkey editor is already there, always was.
       Not "opened" — navigated to.

    4. Press Escape
       → Camera ascends: layer -1 → layer 0
       → Zooms back out to overview
       → Focus returns to the "Alt+Tab" row
