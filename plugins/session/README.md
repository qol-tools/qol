# Session

Lock the screen from one hotkey on Linux, macOS and Windows, for [QoL Tray](../../apps/tray).

</div>

## Quick start

Install from the [QoL Tray](../../apps/tray) plugin store, then bind **Lock Screen** to a hotkey such as `Super+L`.

## About

`qol-session lock` locks the screen. macOS locks through the login framework, Linux asks the running screensaver or logind, and Windows calls `LockWorkStation`. `qol-session doctor` reports which locker this machine will use.
