A game controller fix plugin for [QoL Tray](https://github.com/qol-tools/qol-tray).

## Quick start

Install from the [qol-tray](https://github.com/qol-tools/qol-tray) plugin store.

## About

Detects connected game controllers with known driver defects and applies the matching driver workaround after a single explicit authorization. First entry: the GuliKit Controller XW endless-rumble bug over Bluetooth, fixed with an xpadneo quirk.
