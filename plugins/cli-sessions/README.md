# CLI Sessions

An always-on-top overview of live CLI sessions for [QoL Tray](../../apps/tray).

</div>

## Quick start

Install from the [QoL Tray](../../apps/tray) plugin store.

## About

Tracks any command running in a terminal pane, Claude Code and Codex and Pi and Kimi included, and colors each pane by workflow state so you can see at a glance which session wants attention.

## The panel

Drag any edge or corner to resize the panel; the session list shows more rows when it is taller, and the panel reopens at the size and place you left it.
The panel is never smaller than 360 px wide and tall enough for three sessions.
Press alt+s or the chevron to fold it to its header; a folded panel keeps its height and only its width can be dragged.
Unfolding returns it to the height it had before the fold, at the width it has now, even after the panel was closed or the tray restarted while folded.
