# Update Manager

See what updates wait, install them when you choose, and restart when it suits you.

</div>

## Quick start

```sh
qol-update-manager status
qol-update-manager settings
qol-update-manager doctor
```

## Settings

- The first page says how many updates wait and what finishes at the next restart.
- The waiting list tags every update with its updater: Update Manager, Flatpak or firmware.
- A list longer than 40 shows 40 at a time; the last row moves to the next 40.
- Install asks first, then installs one package at a time.
- Restart tonight waits for Mint's own nightly run; Restart now asks first.
- Update hours and Install on their own change Mint's own settings, and they stay when qol stops.
- Wait while in use and Hold all updates are qol's rules, and they end when qol stops.
