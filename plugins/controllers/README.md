# Controllers

A controller health and compatibility plugin for [QoL Tray](../../apps/qol-tray).

</div>

## Quick start

Install from the [QoL Tray](../../apps/qol-tray) plugin store.

## About

Distinguishes physical and virtual controllers, reports the active driver and rumble capability, and offers compatibility fixes only when they apply to that driver.
