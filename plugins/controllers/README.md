# Plugin Controllers

[![tests](https://github.com/qol-tools/plugin-controllers/actions/workflows/tests.yml/badge.svg)](https://github.com/qol-tools/plugin-controllers/actions/workflows/tests.yml)
[![lint](https://github.com/qol-tools/plugin-controllers/actions/workflows/lint.yml/badge.svg)](https://github.com/qol-tools/plugin-controllers/actions/workflows/lint.yml)

A controller health and compatibility plugin for [QoL Tray](https://github.com/qol-tools/qol-tray).

## Quick start

```bash
make dev
```

Open the Controllers plugin in a QoL Tray development session.

## About

The plugin distinguishes physical and virtual controllers, reports the active driver and rumble capability, and offers compatibility fixes only when they apply to that driver.
