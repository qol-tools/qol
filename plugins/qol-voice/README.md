# QoL Voice

[![tests](https://github.com/qol-tools/qol-voice/actions/workflows/tests.yml/badge.svg)](https://github.com/qol-tools/qol-voice/actions/workflows/tests.yml)
[![lint](https://github.com/qol-tools/qol-voice/actions/workflows/lint.yml/badge.svg)](https://github.com/qol-tools/qol-voice/actions/workflows/lint.yml)

An interruptible speech interaction plugin for [QoL Tray](https://github.com/qol-tools/qol-tray).

## Quick start

```bash
make dev
```

Open QoL Voice in a QoL Tray development session.
