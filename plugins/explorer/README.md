# Explorer

A keyboard-first file explorer, for [QoL Tray](../../apps/tray).

</div>

## Quick start

Install from the [QoL Tray](../../apps/tray) plugin store.

## About

`qol-explorer open` opens the window on the home folder, and `qol-explorer open <path>` opens it on that folder.
