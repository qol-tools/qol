# Key Remap

A keyboard and mouse remapping plugin for [QoL Tray](../../apps/tray).

</div>

## Quick start

Install from the [QoL Tray](../../apps/tray) plugin store.

## About

Runs as a background daemon that intercepts and transforms input events in real time.
