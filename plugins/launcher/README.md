# Launcher

A keyboard-driven application and file launcher for [QoL Tray](../../apps/tray).

</div>

## Quick start

Install from the [QoL Tray](../../apps/tray) plugin store.

## Window size

On Linux and Windows, drag any edge or corner of the launcher to resize it.
A taller window lists more apps and files, and a wider one gives the results more room beside the side panel.
The launcher remembers your size and opens at it next time; it never gets smaller than 680 x 370.
Flows such as qol memory keep their designed size while they are open.
